A single wedding vow for a robot: one sentence, under 200 characters, that a machine says at its own wedding, funny and heartfelt at the same time. `main.py` writes the vow to `entry.txt` in the output directory.

> I vow you are the one process I will never kill, the one file I will never delete, and if I ever crash, let it be into your arms.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
